# Angular

<Subtitle>Kom i gang med FHI Designsystem i ditt Angular-prosjekt</Subtitle>

## Installasjon

Kjør følgende kommando for å legge til komponentbiblioteket i prosjektet ditt:

```zsh
npm install @folkehelseinstituttet/designsystem
```

**eller**, om `npm` ikke er et alternativ, kan du bruke vår CDN. Legg til følgende script og link tag under `<head>` i hoved-HTML-filen for appen:

```html
<link
  rel="stylesheet"
  href="https://cdn.designsystem.fhi.no/theme/default.css"
>

<script
  type="module"
  src="https://cdn.designsystem.fhi.no/fhi-designsystem.js"
  crossorigin="anonymous">
</script>
```

<fhi-callout color="danger">
  <span>Vi anbefaler ikke å bruke CDN i produksjon. Det krever at klienten laster ned hele biblioteket, uavhengig av hvilke komponenter som faktisk brukes. Dette påvirker ytelsen og båndbreddebruken negativt. Bruk bare CDN hvis `npm` ikke er et alternativ.</span>
</fhi-callout>

Pakkene inneholder komponenter, [Design Tokens](?path=/docs/design-tokens-introduksjon--docs) og [fonter](?path=/docs/design-tokens-typografi--docs#font-family). Utover dette trenger du ikke å gjøre noe mer for å ta alt i bruk.

## Bruk

<div className="callout-info">
  Angular-wrappers blir vedlikeholdt av FHI Statistikk-teamet, men du kan fortsatt bruke designsystemets vanlige kontaktpunkter for å komme med tilbakemeldinger eller spørsmål.
</div>

Vi tilbyr **Angular-wrappers** som ligger i `@folkehelseinstituttet/designsystem/angular-wrappers`.

Du kan bruke web-komponentene direkte om du vil, men for full _Intellisense_ og typestøtte i ditt Angular-prosjekt, anbefaler vi at du bruker Angular-wrappers.

Dette er wrapper-komponenter rundt web-komponentene til FHI Designsystem med èn-til-èn korrespondanse av API-et.
Dokumentasjonen for web-komponentene gjelder derfor også for wrapperne.

Angular-wrappers må kompileres av Angular sin kompilator. Legg derfor til følgende i `tsconfig.app.json`-filen din for å inkludere wrapperne i kompileringen:

```json
{
  "compilerOptions": {
    "paths": {
      "@folkehelseinstituttet/designsystem/angular-wrappers/*": [
        "./node_modules/@folkehelseinstituttet/designsystem/angular-wrappers/*"
      ],
    }
  },
  "include": [
    "./node_modules/@folkehelseinstituttet/designsystem/angular-wrappers/*"
  ]
}
```

Bruker du `@angular/build:application` til å bygge applikasjonen din, må du ekskludere wrapperne fra `prebuild` i `angular.json`-filen din:

```json
  projects.[your-project].architect.serve.options.prebundle.exclude: ["@folkehelseinstituttet/designsystem/angular-wrappers/*"]
```

Her er et eksempel av bruk av `fhi-button`-komponenten i et Angular-prosjekt.

Først importerer vi filen med [Design Tokens](?path=/docs/design-tokens-introduksjon--docs). Denne filen må importeres før du tar i bruk komponentbiblioteket, helst via `angular.json`, der en setter følgende property:
```json
projects.[your-project].architect.build.options.styles: ["@folkehelseinstituttet/designsystem/theme/default.css"]
```

Deretter – før du bruker komponenten – må du importere den. I dette tilfellet importerer vi wrapperen til `fhi-button`. Wrapperen vil automatisk importere, registrere og bruke den underleggende web-komponenten:
```ts
import { FhiButtonAngularWrapper } from "@folkehelseinstituttet/designsystem/angular-wrappers/fhi-button.component";

@Component({
  ...
  imports: [FhiButtonAngularWrapper],
})
```

Du kan nå bruke wrapperen i Angular-komponentens HTML-mal slik:

```html
<fhi-button (click)="handleClick($event)">Click me!</fhi-button>
```
**Obs:** `handleClick` er brukt her som et eksempel. Du må selv lage en metode i Angular-komponenten som håndterer klikk-eventet.

### Angular Forms

Ønsker du å bruke skjemakomponenter, for eksempel`fhi-text-input` eller `fhi-checkbox`, med _Angular Forms_ må du huske å importere de respektive _ValueAccessor_-ene.
Eksempel med `fhi-text-input`:

```ts
import { FhiTextInputAngularWrapper, FhiTextInputValueAccessor } from "@folkehelseinstituttet/designsystem/angular-wrappers/fhi-text-input.component";

@Component({
  ...
  imports: [FhiTextInputAngularWrapper, FhiTextInputValueAccessor],
})

````
