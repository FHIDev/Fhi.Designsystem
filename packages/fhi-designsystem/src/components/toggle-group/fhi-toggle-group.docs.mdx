# Toggle Group

Toggle Group lar brukeren velge ett alternativ fra en liste relaterte valg. Valget påvirker innhold eller visning innen samme område.

# Passer til

- Filtrering eller endring av presentasjon lokalt, f.eks. «Dag, uke eller måned».
- Bytting mellom visningstyper, f.eks. «Liste, tabell eller graf».
- Små sett med nært beslektede valg, helst 2 til 5.

<Canvas of={FhiToggleGroupStories.Preview} />
<Controls of={FhiToggleGroupStories.Preview} />


Toggle Group brukes i hovedsak til filtrering eller veksling mellom visninger av innhold. Kun ett alternativ kan være valg om gangen, og endringene vises umiddelbart når valget endrer seg. Toggle Group passer ikke til:

- Å navigere mellom to relaterte sider eller paneler med hvert sitt unike innhold (bruk tabs).
- Skjemaer, hvor dataen lagres eller valideres (bruk Radio).
- Binære “av/på”-valg.

# Innhold

Knappene kan ha tekst, eller ikon til venstre og tekst.  Hold teksten så kort som mulig.
