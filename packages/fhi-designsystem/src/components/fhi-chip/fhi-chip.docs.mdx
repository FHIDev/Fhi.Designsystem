# Chip

Chip viser en valgt verdi som brukeren kan klikke på for å fjerne, for eksempel ved filtrering.

## Passer til

- Å vise aktive filtre eller valg brukeren kan fjerne
- Å la brukeren raskt fjerne én og én valgt verdi fra en gruppe
- Å kommunisere hvilke kriterier som er aktive i en filtrert visning
