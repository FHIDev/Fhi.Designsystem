# Chip

Chip viser en valgt verdi som brukeren kan klikke på for å fjerne, for eksempel ved filtrering.

## Passer til

- Å vise hvilke filtre som er aktive

<Canvas of={FhiChipStories.Preview} />

<Controls of={FhiChipStories.Preview} />

## Eksempler og bruk

Chip fungerer bra til å vise hvilke filtre som er aktive og lar brukeren enkelt fjerne dem.

Skal du merke innhold med kategori som ikke er interaktiv, bruk heller [Tag](https://designsystem.fhi.no/?path=/docs/komponenter-tag--docs).
